# Калькулятор

![Python](https://img.shields.io/badge/Python-3.11-blue)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)
![License](https://img.shields.io/badge/license-MIT-green)

Простой калькулятор с двумя версиями:

- **Веб-версия** (`index.html` + `script.js`) — запускается в браузере.
- **CLI-версия** (`main.py`) — запускается через Python.

## Возможности

- Сложение `+`, вычитание `-`, умножение `*`, деление `/`
- Проверка на деление на ноль
- Валидация ввода (неверные числа, неизвестный оператор, формат выражения)

## Запуск

### Веб-версия
Откройте `index.html` в любом браузере.

### CLI-версия (Python)
```bash
python main.py
```
Введите выражение в формате `число оператор число`, например `5 + 3`.
Для выхода введите `quit`.
